# 十六 (JŪROKU)

4×4 の 16 個の入力領域を使うブラウザ音楽ゲーム。読み込んだ楽曲を解析し、音の立ち上がり
（onset）を検出して自動的にプレイデータ（譜面）を生成する。単一の `index.html` だけで
完結し、ビルド工程もパッケージマネージャも無く、静的ホスティング（Cloudflare Pages）でそのまま配信できる。

## 特徴

- 16 パネルによる瞬間認識型プレイ
- ブラウザ上で完結（インストール不要）
- ローカル音源対応（mp3 / wav / m4a / flac / ogg、端末の外には出ない）
- Suno 楽曲対応
- 自動譜面生成
- BPM グリッドに固定されない、オンセットベースのタイミング
- 同一音源から再現可能な（決定的な）譜面生成
- 5 種類のマーカー
- ワールドツアーモード「Pulse of the Earth」（世界地図を飛行機で巡り、各国の音楽をプレー）
- 結果画面は 冴→良→甘→逃 の順に数が刻まれ、最後に判定・点数・精度が現れる演出（タップで飛ばせる）
- 結果画像（1080×1080 PNG）の保存 — 結果画面と各曲のベスト記録から、同じデザインで
- Google ログインによる記録の同期（任意。ログインしなくても全機能が使える）
- 和風モダン UI
- 独自の判定名称
- キーボード操作対応

## 遊び方

1. タイトル画面から曲を選ぶ（収録曲 / Suno のリンク / 端末内の音源ファイル）
2. 解析（自動で譜面を生成）を待つ
3. プレイ開始。**マーカーが打点に達したタイミングで押す**
   （Press when the marker reaches the Hit Point.）

### 操作

- **キーボード**: `1234` / `QWER` / `ASDF` / `ZXCV`（4×4 パネルに対応）
- **タッチ**: 画面のパネルを直接タップ

### マーカー

ノーツの表示方式は設定画面から 5 種類の中から選べる。既定は **満**。
どれも「打点に達した瞬間が押し時」だが、時間の見せ方がそれぞれ違う。

| マーカー | 打点の示し方 |
|---|---|
| 満 | 下から水位が満ちていき、上端の打点線に届く（既定） |
| 環 | 外周のアークが回転して充填され、一周する |
| 火 | 渦を巻く導火線を火花が中心へ走り、燃え尽きて「ドン」 |
| 簾 | 左から右へ掃引され、右端に届く |
| 蚊 | 蚊が飛来し、中央の丸（打点）に入る |

どのマーカーも、打点を過ぎた後は同じ向きへそのまま進み続けるので（水が上へ抜ける／弧が回り続ける／
火花が中心を抜ける／簾の後端が追いつく／蚊が反対側へ抜ける）、押すのが遅れた量が見た目で分かる。

設定画面ではマーカーと打点音をその場で試せる。選んだマーカーは `localStorage` に
保存され、次回以降も維持される。

### 記録の同期（任意）

設定画面の「アカウント」から Google でログインすると、**ベスト記録・ワールドツアーの進行・
追加したリンク曲**がクラウドに保存され、別の端末でも続きから遊べる。

- ログインしない場合も全機能が使える。その時データは端末の中だけに保存され、外部に送られない
- 同期される記録は「失われない方」で併合される（スコアは高い方、クリアは両方、リンク曲は重複排除）
- 端末ごとの設定（OFFSET・マーカー・打点音・バイブ）と読み込んだ音源は同期されない
- 設定画面からいつでもクラウドのデータを削除できる。詳細は[プライバシーポリシー](privacy.html)

### 結果画像の保存

結果画面、または収録曲カードのベスト記録をタップして出る画面の「画像を保存」で、
曲名・段位・点数・精度・判定内訳・最大コンボ・日付（ワールドツアー曲は国名も）を載せた
1080×1080 の PNG を保存できる（どちらから作っても同じ画像）。スマホでは共有シート、PC ではダウンロード。

### 判定とスコア

| 判定 | 読み | 許容 | 素点 |
|---|---|---|---|
| 冴 | SAE | ±45ms | 100 |
| 良 | RYŌ | ±90ms | 70 |
| 甘 | AMA | ±140ms | 30 |
| 逃 | NOGASHI | それ以上 / 未押下 | 0 |

コンボは逃でのみ切れる（甘では継続）。スコアはコンボ倍率（最大 ×1.5、120コンボで上限）を
含むが、段位は**精度**（コンボ倍率を含まない素点の割合）で決まる。

| 段位 | 極 | 秀 | 優 | 良 | 可 | 不可 |
|---|---|---|---|---|---|---|
| 精度 | 97%〜 | 92%〜 | 84%〜 | 70%〜 | 50%〜 | 〜50% |

### ワールドツアー「Pulse of the Earth」

タイトル画面の「ワールドツアー」タブから。1 枚の世界地図（点描・選んだ国が中央に来る）の上を
飛行機で移動し、その国の伝統音楽×エレクトロの楽曲をプレーする。楽曲は番号順に 1 曲ずつ解放され、
**可以上**でクリアすると次の国へ進める（難易度は出発ごとに選べる。どの難易度でもよい）。

- クリアした国には朱印が押され、飛んだ航路が金の線で残る
- クリアした曲は「収録曲」タブにも国旗・国名付きで並び、いつでも遊べる
- Vol を完走すると次の Vol が現れ、前 Vol の最終国から旅が続く

| Vol | 行程 | 曲数 |
|---|---|---|
| Vol.1 | 🇯🇵 JAPAN → 🇨🇳 CHINA → 🇮🇳 INDIA → 🇪🇬 EGYPT → 🇫🇷 FRANCE → 🇪🇸 SPAIN → 🇧🇷 BRAZIL → 🇺🇸 USA | 8 |
| Vol.2 | 🇲🇽 MEXICO → 🇨🇺 CUBA → 🇯🇲 JAMAICA → 🇦🇷 ARGENTINA → 🇦🇺 AUSTRALIA → 🇮🇩 INDONESIA → 🇲🇳 MONGOLIA → 🇮🇪 IRELAND | 8 |
| Vol.3 | 🏴󠁧󠁢󠁳󠁣󠁴󠁿 SCOTLAND → 🇩🇪 GERMANY → 🇮🇹 ITALY → 🇬🇷 GREECE → 🇹🇷 TURKEY → 🇳🇬 NIGERIA → 🇿🇦 SOUTH AFRICA → 🇰🇷 KOREA | 8 |

進行は `localStorage`（`juroku:tour`）に保存される。

### 譜面生成

音声をモノラル化して短時間フーリエ変換にかけ、帯域ごとのスペクトル差分から
オンセットを検出してノーツを置く。BPM 推定・グリッド量子化は行わず、生の
オンセット位置をそのまま使う。乱数のシードは音声内容のハッシュなので、
同じ音源からは常に同じ譜面が生成される（決定的）。

## ローカルでの動かし方

Web Audio API と Suno CDN からの音源取得のため HTTPS（または `localhost`）が必要。
`index.html` を `file://` で直接開いても CORS で音源が読み込めず動作しない。

```bash
python3 -m http.server -d public
```

起動後、`http://localhost:8000/` をブラウザで開く。
（`functions/` はローカルでは動かないため、記録の同期は無効な状態で表示される）

## 技術メモ

- 単一 HTML ファイル構成（意図的な設計。分割しない）。配信物は `public/`、サーバー側は `functions/`
- ホーム画面に追加すると「十六」のアイコンで起動する（`site.webmanifest` / apple-touch-icon）
- 外部依存は Google Fonts（Shippori Mincho / Zen Kaku Gothic New / JetBrains Mono）のみ
- ベストスコア・設定は `localStorage` に保存される（プライベートブラウジング等で
  使えない場合は保存されないだけでアプリ自体は動作する）

開発上の制約・設計方針の詳細は [CLAUDE.md](CLAUDE.md) を参照。
